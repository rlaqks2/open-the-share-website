# 현재 웹사이트 기획 명세서 (Current Specifications)

이 문서는 현재 개발된 웹사이트의 구조와 기능을 정리한 것입니다.
기획자님께서는 **[기획 수정 사항]** 섹션에 변경 요청 사항을 작성해주시면 됩니다.

---

## 1. 사이트 구조 (Site Structure)
현재 웹사이트는 **싱글 페이지 애플리케이션 (Single Page Application)** 형태입니다.
상단 네비게이션을 클릭하면 해당 섹션으로 스크롤 이동합니다.

### 네비게이션 메뉴 (Header)
| 메뉴명 | 연결 섹션 | 기능/설명 |
| --- | --- | --- |
| **회사소개** | `#about` | 회사 비전 및 소개 섹션으로 이동 |
| **사업소개** | `#programs` | 주요 사업 및 프로그램 소개 섹션으로 이동 |
| **포트폴리오** | `#portfolio` | 진행한 프로젝트 목록 섹션으로 이동 |
| **소식** | `#testimonials` | 현재 고객 후기 섹션으로 연결됨 (수정 필요?) |
| **FAQ** | `#faq` | 자주 묻는 질문 섹션으로 이동 |

### **[기획 수정 사항]**
> - **[변경]** "사업소개" 하위 메뉴/섹션 명확화: "주요 사업 분야", "진행 프로세스" (프로그램 진행 절차 -> 진행 프로세스 로 변경 필요해 보임).
>

## 2. 페이지 구성 (Page Layout)

### 2.1 메인 비주얼 (Hero Section)
- **구성**: 대형 배경 이미지/영상, 메인 카피 문구, 파트너십 문의 버튼.
- **기능**: '파트너십 문의' 클릭 시 문의 모달 팝업.

### 2.2 회사 소개 (About Section)
- **구성**: 회사 가치(Mission, Vision) 및 소개 텍스트.

### 2.3 임팩트 (Impact Section)
- **구성**: 숫자 데이터(참여 기업 수, 기부액 등)를 강조하여 성과를 보여줌.

### 2.4 사업 분야 (Programs Section)
- **구성**: 제공하는 주요 서비스/프로그램 카드 나열.

### 2.5 진행 프로세스 (Process Section)
- **구성**: 서비스 이용 절차 단계별 안내.

### 2.6 포트폴리오 (Portfolio Section)
- **구성**: 프로젝트 썸네일 그리드.
- **기능**: 아이템 클릭 시 상세 정보 모달(Portfolio Detail Modal) 팝업.

### 2.7 고객 후기 (Testimonials Section)
- **구성**: 파트너/고객사 담당자 인터뷰 또는 후기 슬라이드/그리드.

### 2.8 파트너사 (Partners Section)
- **구성**: 협력 기업 로고 그리드.

### 2.9 FAQ (FAQ Section)
- **구성**: 자주 묻는 질문 아코디언 (접기/펼치기).

### 2.10 하단 CTA (Call To Action)
- **구성**: "지금 바로 시작하세요" 문구와 문의하기 버튼.
- **기능**: 버튼 클릭 시 문의 모달 팝업.

### **[기획 수정 사항]**
> - **[텍스트 변경]** "프로그램 진행 절차" -> "진행 프로세스"
> - **[주요 사업 분야 (Programs)]** 각 아이템 타이틀/내용 변경 요청:
>    - 1. 나눔물품 제작기부 -> **원데이메이킹 사회공헌**
>    - 2. 미래세대 육성 -> **찾아가는 과학교실**
>    - 3. 취약계층 노후공간 리모델링 -> **스페이스 업사이클링**
>    - 4. 친환경 사회공헌 -> **식목/플로깅/친환경 테마공원 조성**
> - **[포트폴리오]**
>    - 프로젝트 개요 -> 설명 한 줄 형태로 변경.
>    - 상세 설명 부분에 "블로그 보러가기" 버튼 생성 (해당 블로그 연결).
> - **[고객 후기 (Testimonials)]**
>    - 이름 마스킹 처리 (김*준, 박*연, 이*호).
>    - "의미 있는 프로그램" -> "**의미 있는 사회공헌 프로그램**".
>    - "결과 보고서" -> "**소셜임팩트리포트**".
> - **[파트너사 (Partners)]**
>    - 섹션 타이틀: "주요 고객사" -> "**주요 파트너사**".
>    - 이미지 추가: 대기업/공기업 위주로 5줄 정도 배너 배치 (참고: https://blog.naver.com/5penthe/223772948561).
> - **[FAQ]**
>    - Q: "프로그램 비용은?" -> "**프로그램 견적은?**" 으로 변경.
>    - Q: "ESG 보고서 활용..." 질문 -> **삭제**.
>    - 답변 내용 수정 (Q1 정해진 프로그램..., Q4 견적 문의...).
>

## 3. 공통 기능 및 모달 (Features & Modals)

### 3.1 헤더 기능 (Header)
- **검색**: 돋보기 아이콘 클릭 시 검색 모달 (`SearchModal`) 출력.
- **로그인/회원가입**:
    - 로그인 버튼 클릭 시 로그인 모달 (`LoginModal`) 출력.
    - 로그인 모달 내에서 '회원가입', '계정 찾기' 로 이동 가능.
- **파트너십 문의**: 문의 버튼 클릭 시 문의 모달 (`InquiryModal`) 출력.
- **반응형**: 모바일 화면에서는 햄버거 메뉴 제공.

### 3.2 푸터 (Footer)
- **정보**: 회사 정보(대표자, 주소, 연락처), 저작권 표시.
- **링크**: 이용약관, 개인정보처리방침 (현재 링크 비활성화 상태), 소셜 미디어 아이콘.

### 3.3 상세 기능
- **포트폴리오 상세**: 리스트 아이템 클릭 시 팝업으로 상세 내용(이미지, 설명, 기간, 참여자 수 등) 표시.
- **로그인 상태 관리**: 현재 프론트엔드 전용 상태 관리 (새로고침 시 초기화됨).

## 4. 데이터 구조 (Data Models)
현재 포트폴리오 아이템의 데이터 구조는 다음과 같습니다.

```typescript
interface PortfolioItem {
  id: number;           // 고유 번호
  title: string;        // 프로젝트명
  category: string;     // 분류 (예: IT 기업 연합)
  imageUrl: string;     // 이미지 경로
  partner: string;      // 파트너사
  period: string;       // 기간
  participants: number; // 참여 인원
  story: string;        // 상세 내용
  blogLink?: string;    // 블로그 링크 (선택)
}
```
