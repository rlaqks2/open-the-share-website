# 웹사이트 기획 명세서 (Website Specification - Final)

이 문서는 개발 완료 예정인 웹사이트의 **최종 기획 내용**을 담고 있습니다. 
기존의 수정 요청 사항들이 모두 반영된 상태를 기준으로 작성되었습니다.

---

## 1. 사이트 구조 (Site Structure)

웹사이트는 **싱글 페이지 애플리케이션 (SPA)** 형태이며, 상단 네비게이션을 통해 각 섹션으로 스크롤 이동합니다.

### 네비게이션 메뉴 (Header)
로그인/회원가입 기능 없이, 심플한 정보 제공 및 문의 유도에 집중합니다.

| 메뉴명 | 연결 섹션 | 설명 |
| --- | --- | --- |
| **회사소개** | `#about` | 기업 비전 및 미션 소개 |
| **사업소개** | `#programs` | 주요 사업 분야 및 진행 프로세스 소개 |
| **포트폴리오** | `#portfolio` | 프로젝트 수행 사례 목록 |
| **소식** | `#testimonials` | 주요 파트너 및 고객 후기 |
| **FAQ** | `#faq` | 자주 묻는 질문 |
| **(버튼) 파트너십 문의** | `InquiryModal` | 우측 상단 강조 버튼. 클릭 시 문의 팝업 노출 |

---

## 2. 페이지 구성 (Page Layout)

### 2.1 메인 비주얼 (Hero Section)
- **구성**: 대형 배경 이미지/영상, 메인 슬로건.
- **기능**: '파트너십 문의' 버튼 포함 (클릭 시 문의 모달).

### 2.2 회사 소개 (About Section)
- **내용**: 
    - "기업의 ESG 경영을 위한 최적의 사회공헌 파트너, 오픈더쉐어"
    - 기업의 가치(Mission, Vision) 및 서비스 철학 소개.

### 2.3 임팩트 (Impact Section)
- **내용**: 누적 파트너사, 프로그램 진행 건수 등 성과 지표를 숫자로 강조.

### 2.4 주요 사업 분야 (Programs Section)
다음 4가지 핵심 프로그램을 소개합니다.
1. **원데이메이킹 사회공헌**: 참여형 핸즈온 봉사활동.
2. **찾아가는 과학교실**: 창의 과학 교육 프로그램.
3. **스페이스 업사이클링**: 취약계층 노후 공간 리모델링.
4. **식목/플로깅/친환경 테마공원 조성**: 지속 가능한 환경 활동.

### 2.5 진행 프로세스 (Process Section)
서비스 이용 절차를 단계별로 안내합니다.
1. 컨설팅 및 요구분석
2. 프로그램 기획 및 제안
3. 실행 및 운영
4. **소셜임팩트리포트** 및 피드백

### 2.6 포트폴리오 (Portfolio Section)
- **목록 화면**: 
    - 프로젝트 썸네일 카드 그리드.
    - 각 카드는 프로젝트명과 **한 줄 요약** 설명 제공.
- **상세 팝업 (Modal)**: 
    - 클릭 시 상세 정보(파트너사, 기간, 참여인원, 상세 스토리) 표시.
    - **"블로그 보러가기"** 버튼을 통해 관련 블로그 게시글로 연결.

### 2.7 고객 후기 (Testimonials Section)
- **내용**: 파트너사 담당자 및 참가자의 긍정적 후기.
- **표시 방식**: 작성자 이름은 마스킹 처리 (예: 김*준). 문구 내 "의미 있는 **사회공헌** 프로그램" 강조.

### 2.8 주요 파트너사 (Partners Section)
- **구성**: 주요 대기업 및 공기업 파트너사의 로고/배너 이미지 배치 (5줄 가량의 풍성한 배너 형태).

### 2.9 FAQ (FAQ Section)
- **주요 질문**:
    - 프로그램 **견적**은 어떻게 산정되나요?
    - 정해진 사회공헌 프로그램을 선택하는 방식인가요?
    - 지방에서도 프로그램 진행이 가능한가요?
- (ESG 보고서 활용 관련 질문은 포함되지 않음)

### 2.10 하단 CTA (Call To Action)
- **기능**: 페이지 하단에서 최종적으로 파트너십 문의를 유도하는 섹션.

## 3. 기능 및 모달 (Features & Modals)

### 3.1 파트너십 문의 모달 (InquiryModal)
- **진입점**: 헤더의 '파트너십 문의' 버튼, 메인 비주얼 버튼, 하단 CTA 버튼.
- **기능**:
    - 담당자 정보(이름, 연락처, 이메일, 회사명) 및 문의 내용 입력 폼.
    - **닫기 버튼(X)**: 우측 상단에 위치하여 언제든 닫기 가능.
- **전송 피드백**:
    - **성공 시**: "신청이 접수되었습니다" 메시지와 녹색 체크 아이콘 팝업.
    - **실패 시**: "신청이 실패하였습니다" 메시지와 붉은색 X 아이콘 팝업 (재시도 버튼 포함).

### 3.2 검색 모달 (SearchModal)
- 헤더의 돋보기 아이콘 클릭 시, 사이트 내 콘텐츠 검색 기능 제공.

### 3.3 (삭제됨) 회원 기능
- 로그인, 회원가입, 계정 찾기 기능은 제공하지 않음.

## 4. 데이터 모델 (Data Models)

### PortfolioItem
```typescript
interface PortfolioItem {
  id: number;
  title: string;        // 프로젝트명
  category: string;     // 분류 (예: 주거개선)
  imageUrl: string;     // 썸네일 이미지
  partner: string;      // 주요 파트너사
  period: string;       // 진행 기간
  participants: number; // 참여 인원
  story: string;        // 프로젝트 상세 스토리
  blogLink?: string;    // 관련 블로그 링크
}
```
